Serial Printer Sale Personalization v1.3.0

Instalacion Odoo.sh:
1) Borra completamente la carpeta antigua addons/serial_printer_sale_personalization.
2) Sube esta carpeta nueva serial_printer_sale_personalization directamente dentro de addons/.
3) Commit y espera el build verde en Odoo.sh.
4) En Odoo: Apps > Actualizar lista de aplicaciones.
5) Busca: Serial Printer Sale Personalization.
6) Instala.

Importante:
- No mezclar archivos de versiones anteriores.
- Este ZIP no incluye security.xml para evitar grupos/categorias incompatibles entre Odoo 18/19.
- Los permisos se cargan con ir.model.access.csv sin grupo para facilitar instalacion inicial.
